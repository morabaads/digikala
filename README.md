# DK Bridge — انتقال ووکامرس به دیجی‌کالا

افزونهٔ وردپرس برای **انتقال محصولات ووکامرس به پنل فروشندگان دیجی‌کالا** از طریق [Open API رسمی](https://seller.digikala.com/open-api/v1/doc/)، **اصلاح خودکار محتوا طبق قوانین دیجی‌کالا** و **همگام‌سازی دوطرفهٔ موجودی، قیمت و سفارش**.

📄 سند کامل نیازمندی‌ها، معماری و ایده‌ها: [`docs/PRD.md`](docs/PRD.md)

## امکانات

| | |
| --- | --- |
| 🔌 **اتصال** | توکن شخصی پنل فروشنده (Self-Token) یا اپلیکیشن ثبت‌شده (OAuth)، ذخیرهٔ رمزنگاری‌شدهٔ توکن، تمدید خودکار |
| 🧠 **موتور قوانین** | ۴۰+ قانون محتوا: عنوان طبق فرمول «ماهیت + برند + مدل»، حذف کلمات تبلیغاتی، تماس، قیمت و گارانتی از عنوان، رنگ و سایز در گروه‌های تنوع‌دار، کالای غیراصل بدون برند، عنوان انگلیسی لاتین، پاک‌سازی HTML و اطلاعات تماس از توضیحات، نقاط قوت و ضعف، ویژگی‌های اجباری، ابعاد در بازهٔ مجاز گروه، شناسهٔ کالا |
| 🛠 **اصلاح خودکار** | یک کلیک برای رفع ایرادها؛ نتیجه در «محتوای اختصاصی دیجی‌کالا» ذخیره می‌شود و **محتوای سایت دست نمی‌خورد** |
| 📊 **امتیاز آمادگی** | هم‌وزن با امتیاز محتوای دیجی‌کالا (`score_details`)، با جزئیات هر بخش |
| 🖼 **سفیدکار تصویر** | مربع، پس‌زمینهٔ سفید، Trim و پرکردن ۸۸٪ قاب، تبدیل WebP/PNG شفاف به JPG، حذف EXIF، کنترل ابعاد و حجم، + بررسی هوش مصنوعی خود دیجی‌کالا |
| 🔁 **ضد تکراری** | قبل از ساخت، کالای مشابه در دیجی‌کالا جستجو می‌شود تا فقط تنوع روی کالای موجود ساخته شود |
| 🚀 **Pipeline قابل ازسرگیری** | پیش‌نویس ← ویژگی‌ها ← عنوان ← تصاویر ← ذخیره ← پایش تأیید ← ساخت تنوع‌ها (رنگ/سایز با تطبیق نام، مترادف و HEX) |
| 💰 **قیمت‌گذاری هوشمند** | تومان به ریال، سود درصدی و ثابت، جبران کمیسیون، رُند کردن (عادی/بالا/پایین/روانی)، رعایت بازهٔ قیمت مجاز، هشدار زیر سود |
| 📦 **همگام‌سازی** | موجودی و قیمت با Batch API هر ۵ و ۱۵ دقیقه، بافر ضد Oversell، کسر موجودی ووکامرس با سفارش‌های دیجی‌کالا و بازگرداندن با لغو یا مرجوعی |
| 🔔 **وب‌هوک و اعلان** | دریافت رویدادهای تأیید محتوا و سفارش، ایمیل تأیید یا رد |
| 🧪 **اجرای آزمایشی** | کل مسیر بدون ارسال درخواست تغییردهنده، با پیش‌نمایش JSON همهٔ درخواست‌ها |
| 🧰 **توسعه‌دهنده** | WP-CLI (`wp dkb …`)، Hookهای متعدد، لاگ ساختاریافته و خروجی CSV |

## نصب

1. پوشهٔ مخزن را با نام `dk-bridge` در `wp-content/plugins/` قرار دهید (یا zip کنید و از «افزودن افزونه» بارگذاری کنید). پوشه‌های `docs/`، `tests/` و `vendor/` برای اجرا لازم نیستند.
2. افزونه را فعال کنید (ووکامرس باید فعال باشد).
3. **دیجی‌کالا ← تنظیمات ← اتصال**: کد فروشنده و Access Token را وارد کنید و «تست اتصال» را بزنید.
4. **نگاشت دسته‌ها**: هر دستهٔ ووکامرس را به گروه برگ دیجی‌کالا وصل کنید (دکمهٔ «پیشنهاد» کمک می‌کند).
5. **تنظیمات ← قیمت‌گذاری**: واحد پول، درصد سود و جبران کمیسیون را تنظیم کنید.
6. **محصولات**: «بررسی» ← «اصلاح خودکار» ← «ارسال».

> ⚠️ Open API دیجی‌کالا فقط از سرورهایی پاسخ می‌دهد که به شبکهٔ دیجی‌کالا دسترسی دارند (معمولاً IP ایران). برای اولین بار «اجرای آزمایشی» را روشن کنید و پیش‌نمایش درخواست‌ها را بررسی کنید.

## WP-CLI

```bash
wp dkb status
wp dkb search-category "گوشی موبایل"
wp dkb map-category 15 11
wp dkb validate --all --fix
wp dkb push 123 124 --now
wp dkb push --all
wp dkb sync-stock --all
wp dkb sync-prices
wp dkb pull-orders
wp dkb poll
```

## Hookها

| Hook | نوع | کاربرد |
| --- | --- | --- |
| `dkb_product_data` | filter | تغییر داده‌های محصول پیش از اجرای قوانین |
| `dkb_rules` | filter | افزودن یا حذف قانون (`\DKBridge\Rules\Rule`) |
| `dkb_product_payload` | filter | تغییر بدنهٔ درخواست‌ها (`details`, `attributes`, `title`, `save`, `edit`) |
| `dkb_variant_payload` | filter | تغییر بدنهٔ ساخت تنوع |
| `dkb_calculated_price` | filter | تغییر محاسبهٔ قیمت (ریال) |
| `dkb_seller_stock` | filter | تغییر موجودی ارسالی |
| `dkb_decrypt_authorization_code` | filter | رمزگشایی کد مجوز اپلیکیشن OAuth |
| `dkb_before_push` / `dkb_after_push` | action | قبل و بعد از ارسال |
| `dkb_order_item_received` | action | ثبت قلم سفارش جدید دیجی‌کالا |
| `dkb_webhook_received` | action | هر وب‌هوک دریافتی |

## توسعه و تست

```bash
composer install
composer test
composer lint
```

تست‌ها لایهٔ دامنه (نرمال‌سازی فارسی، قوانین، عنوان، قیمت، تصویر)، کلاینت API (با transport جعلی: retry، 429، تمدید توکن، dry-run، محدودیت نرخ) و Pipeline ساخت کالا (ازسرگیری، تلاش دوباره برای عنوان) را پوشش می‌دهند.

## ساختار

```
dk-bridge.php            بوت‌استرپ افزونه
includes/
  Api/                   Client (HTTP، retry، rate limit، refresh)، Digikala (اندپوینت‌ها)، TokenStore
  Rules/                 RuleEngine + Checks/* (قوانین محتوا) + Issue
  Text/                  Normalizer، ContentSanitizer، TitleBuilder
  Images/                ImageProcessor (GD)
  Pricing/               PriceCalculator
  Matching/              Similarity (فازی فارسی/انگلیسی، رنگ)
  Mapping/               ProductMapper، CategoryMapper، AttributeMapper، BrandResolver، VariantMapper، PayloadBuilder
  Sync/                  Publisher (Pipeline)، InventorySync، OrderSync، StatusPoller، WebhookController، Queue
  Admin/                 صفحات، جدول محصولات، متاباکس، REST مدیریتی
  Cli/                   فرمان‌های WP-CLI
assets/                  admin.js / admin.css (بدون Build)
docs/PRD.md              سند نیازمندی‌های محصول
tests/                   PHPUnit
```
